## 논문이 커버하는 각도 (angle)

본 논문은 여러 각도로 제출 가능:

| 각도 | 핵심 메시지 |
|------|-----------|
| A. AI/Expert System | 7분야 통합 검증 expert system + K-voting + RAG |
| B. Process Safety | PSM 기반 사고 예방, cross-discipline 위험 탐지 |
| C. Construction/EPC Automation | EPC 라이프사이클 검증 자동화 |
| D. Regulatory/Compliance AI | Jurisdiction compliance gap 개념, 규제 RAG |
| E. NLP/Information Retrieval | BM25 + synonym expansion for Korean regulatory corpus |
| F. 국내 학회 (한국어) | KOSHA/PSM 실무 적용, 한국 산업안전 |

## Tier 1 — SCI 국제 저널 (IF 5+)

### 1. Expert Systems with Applications (Elsevier)
| 항목 | 내용 |
|------|------|
| IF | ~8.5 | Q1 CS-AI |
| 각도 | A (Expert System) |
| 논문 | `PAPER_1_ESWA.md` |
| 리뷰 | 8-12주 |
| 강점 | AI system paper 최적, synthetic data 수용 |
| 리스크 | 낮음 |

### 2. Automation in Construction (Elsevier)
| 항목 | 내용 |
|------|------|
| IF | ~10.3 | Q1 Civil/Construction |
| 각도 | C (EPC Automation) |
| 논문 | `PAPER_2_AIC.md` |
| 리뷰 | 10-16주 |
| 강점 | IF 최고, EPC 독자 직접 도달 |
| 리스크 | 중간 (field data 요구 가능) |

### 3. Journal of Loss Prevention in the Process Industries (Elsevier)
| 항목 | 내용 |
|------|------|
| IF | ~3.6 | Q2 Chemical Engineering / Safety |
| 각도 | **B (Process Safety)** |
| 리뷰 | 8-12주 |
| 강점 | **프로세스 안전 분야 핵심 저널.** KOSHA/PSM, cross-discipline hazard, 사고 예방이 정확히 이 저널의 스코프. Selvam et al. (2026) [참고문헌 1]이 바로 이 저널에 게재됨 — 직접적 대화 가능 |
| 리스크 | 낮음 — screening-level 시스템도 수용, synthetic data OK |
| 비고 | IF는 낮지만 **프로세스 안전 분야에서 가장 영향력 있는 저널 중 하나** |

### 4. Computers in Industry (Elsevier)
| 항목 | 내용 |
|------|------|
| IF | ~8.2 | Q1 CS-Interdisciplinary |
| 각도 | A + C (AI + Industry Automation) |
| 리뷰 | 10-14주 |
| 강점 | "AI for industrial applications" 스코프에 정확히 부합. 산업 AI 시스템 논문에 개방적 |
| 리스크 | 낮음-중간 |

### 5. Engineering Applications of Artificial Intelligence (Elsevier)
| 항목 | 내용 |
|------|------|
| IF | ~7.5 | Q1 CS-AI / Engineering |
| 각도 | A (Engineering AI) |
| 리뷰 | 8-14주 |
| 강점 | ESWA와 유사 스코프이나 **공학 응용에 더 특화**. 7분야 통합이 강점으로 작용 |
| 리스크 | 낮음 |

### 6. Safety Science (Elsevier)
| 항목 | 내용 |
|------|------|
| IF | ~4.7 | Q1 Safety / Public Health |
| 각도 | **B + D (Safety + Regulatory)** |
| 리뷰 | 10-16주 |

| 리스크 | 낮음 — 규제 관점 강조 시 synthetic data 문제 최소화 |

### 7. Reliability Engineering & System Safety (Elsevier)
| 항목 | 내용 |

| 리스크 | 중간 — reliability 분야 전통적 방법론과의 비교 요구 가능 |

### 8. Process Safety and Environmental Protection (Elsevier)
| 항목 | 내용 |

## 추천 조합 전략

### 전략 A: 안전하고 빠른 게재 우선
```
1차: Applied Sciences (MDPI) — 4-6주 리뷰, 높은 수용률
2차: J. Computational Design & Engineering — 한국 공학 AI 친화
3차: 워크샵 병행
```

### 전략 B: 최대 임팩트 추구
```
1차: ESWA (IF 8.5) 또는 Reliability Eng. & System Safety (IF 8.1)
2차: Reject 시 → Automation in Construction (IF 10.3)
3차: 워크샵 병행
```

### 전략 C: 프로세스 안전 분야 집중
```
1차: Process Safety and Environmental Protection (IF 6.9)
  또는 Safety Science (IF 4.7) — jurisdiction gap 개념이 가장 잘 맞음
2차: J. Loss Prevention in the Process Industries (IF 3.6) — 참고문헌 [1]과 직접 대화
3차: 한국안전학회지 (한국어 버전)
```

### 전략 D: 한국 학술 생태계 활용
```
1차: J. Computational Design & Engineering (Oxford/KSME, IF 4.9)
2차: Korean J. Chemical Engineering (Springer/KIChE, IF 2.7)
3차: 한국안전학회지 (KCI)
```
